# Empanadas Rey - Landing Page 🥟👑

## Descripción del Proyecto
Este repositorio contiene una maqueta funcional de una landing page diseñada para **Empanadas Rey**, un negocio local. Construida bajo un enfoque **Mobile-First**, la página funciona como un catálogo digital interactivo que optimiza la conversión conectando los pedidos directamente a WhatsApp.

## Características
* 📱 **Mobile-First Design:** Interfaz optimizada para una navegación fluida en dispositivos móviles.
* 💬 **Pedidos por WhatsApp:** Redirección directa con mensajes prellenados según el producto seleccionado, agilizando el proceso de compra.
* 🚀 **Carga Ultrarrápida:** Arquitectura front-end ligera y estática. Cero uso de bases de datos relacionales como MySQL, lo que garantiza tiempos de respuesta mínimos y máxima seguridad.
* 🎨 **UI/UX:** Animaciones en CSS puro (`fade-up`, `sway`), diseño moderno con clip-paths y estructura responsiva.

## Tecnologías Utilizadas
* HTML5 & CSS3
* Bootstrap 5
* jQuery
* Google Fonts (Anton & Plus Jakarta Sans)
* Bootstrap Icons
